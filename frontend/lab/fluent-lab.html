组件注册与官方命名映射

05

Fluent v3 的组件命名与设计稿并非一一对应。下表按真实注册状态展示，不只按文档名称推测。

设计需求官方元素状态说明
Buttonfluent-button检查中主要、次要、轻量、禁用
Text Fieldfluent-text-input + fluent-field检查中v3 中替代 TextField 命名
Checkboxfluent-checkbox检查中原生表单事件
Switchfluent-switch检查中主题与表单状态
Selectfluent-dropdown + fluent-listbox检查中v3 中替代 Select 命名
Dialogfluent-dialog检查中模态与焦点管理
Menufluent-menu + fluent-menu-list检查中Popover API
Tooltipfluent-tooltip检查中锚点与延迟
Progress Barfluent-progress-bar检查中确定进度
Progress Ringfluent-spinner检查中3.2.1 无 Progress Ring，使用 Spinner
Accordionfluent-accordion + fluent-accordion-item检查中单选/多选展开
