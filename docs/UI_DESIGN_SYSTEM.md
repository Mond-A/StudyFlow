# StudyFlow UI Design System

> Paper & Ink · 轻盈、清晰、可靠的学习工作台  
> 适用于当前 Flask + 原生 HTML/CSS/JS 架构，不依赖前端框架。

## 1. 设计原则

1. **内容优先**：留白、层级和字号先于装饰。页面不靠渐变和玻璃效果制造“高级感”。
2. **一处一行动**：每个页面只有一个最明确的主操作；次要信息降级到辅助区。
3. **从纸到屏**：暖白页面、深墨侧栏、克制的蓝色主行动色，形成 StudyFlow 自己的“学习工作台”气质。
4. **紧凑但不拥挤**：桌面端学习 Linear 的信息密度，移动端使用更大的点击区和更短的决策路径。
5. **状态透明**：演示 AI、真实 AI、加载、错误、空状态都必须有清晰文案与视觉区分。

## 2. 色彩

语义 token 定义在 [`frontend/css/base.css`](../frontend/css/base.css)：

| Token | 用途 |
| --- | --- |
| `--bg` / `--surface` | 页面底色 / 卡片表面 |
| `--ink` / `--ink-soft` / `--muted` / `--muted-light` | 主文、正文、辅助、标签 |
| `--primary` | 主操作、关键链接、选中态 |
| `--teal` / `--amber` / `--violet` | 学习数据分类与辅助状态 |
| `--success` / `--danger` | 成功 / 危险 |
| `--sidebar` / `--sidebar-text` / `--sidebar-muted` | 深色导航 |

颜色使用规则：

- 主蓝只承担“可操作”和“当前选中”，不用于大面积装饰。
- 语义色只承担含义；小字号状态文字使用深色变体（例如 `--amber-ink`）。
- 辅助文字 `--muted-light` 在页面底色上的对比度不低于 4.5:1。
- 未来深色主题应从语义 token 出发扩展，不在页面 CSS 中写死颜色。

## 3. 字体与字号

系统字体优先，避免依赖外部字体加载：

```css
-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI Variable Text",
"Segoe UI", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif
```

| 层级 | 字号 | 说明 |
| --- | ---: | --- |
| 页面标题 | 28–34px | clamp，移动端仍保持 27px 左右 |
| 区块标题 | 20px | 页面区块 |
| 卡片标题 | 16px | 模块标题 |
| 正文 | 14px | 页面正文与说明 |
| 紧凑正文 | 13px | 表格、辅助段落 |
| 元信息 | 12px | 标签、日期、状态、表格表头 |

全站不再使用低于 12px 的可见字号。

## 4. 尺寸、圆角与阴影

| Token | 值 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | 8px | 标签/小控件 |
| `--radius-md` | 10px | 输入框、按钮、图标按钮 |
| `--radius-lg` | 14px | 卡片 |
| `--radius-xl` | 18px | 浮层、重要卡片 |
| `--control-height` | 42px | 桌面控件；移动端 44px |
| `--shadow-xs/sm/md/lg` | 分层 | 卡片、浮层、Modal |

桌面主按钮 42px，移动端 44px；移动端图标按钮 40px；卡片内紧凑操作不得成为唯一入口。

## 5. 间距

保留 4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。

- 页面外边距：桌面 32–36px，1024 约 28px，平板 18–20px，手机 12–14px。
- 卡片内边距：桌面 22px，手机 16px。
- 区块间距：桌面 18–20px，手机 14–16px。

## 6. 响应式策略

| 视口 | 策略 |
| --- | --- |
| ≥1181px | 固定 248px 侧边栏，4 列指标 |
| 1024–1180px | 侧栏抽屉，页面主内容优先，4 列指标或 2 列内容 |
| 768–1023px | 平板布局，页头纵向堆叠，2×2 指标，侧栏卡片上下排列 |
| ≤767px | 手机布局，2×2 指标，主操作前置；Focus 计时器在摘要之前 |
| ≤600px | 侧栏内容转为单列，Notes 编辑器在选中笔记后自动进入视野 |

页面网格统一在 900px 以下改为单列，1024px 继续保留桌面双栏，以充分利用抽屉导航释放出的宽度。

## 7. 组件规范

- **按钮**：`btn`、`btn-primary`、`btn-secondary`、`btn-ghost`、`btn-sm`、`btn-lg`。禁止无状态反馈的可点击卡片。
- **表单**：输入框与选择器统一高度、聚焦环和边框；字段标签 12.5px，说明 12px。
- **卡片**：使用 `--radius-lg`、`--line` 和轻阴影；只有可点击卡片才具有 hover 抬升。
- **指标带**：Dashboard 的四大指标是一条整合的指标带，而不是四张独立卡片。
- **状态**：空状态、错误状态、加载状态、AI 演示标识、真实 AI 标识都保持独立语义。
- **侧边栏**：AI 状态、用户、版本位于固定区域；移动端关闭时设置为 `inert`，防止键盘焦点进入画外导航。

## 8. 页面构图

| 页面 | 构图策略 |
| --- | --- |
| Dashboard | 今日简报：指标带 + 任务主区 + 目标/成绩/快捷辅助栏 |
| Planner | 任务主列表 + 排期侧栏；桌面悬浮排期，平板排期前置 |
| Analytics | 指标带 + 两张趋势图 + 比较/解读 + 成绩明细，图表优先 |
| AI Toolbox | 工具导航 + 当前工具舞台；模型状态前置，结果区渐进呈现 |
| Notes | 笔记列表 + 编辑工作区；桌面分栏，手机选中后自动滚动到编辑器 |
| Focus | 沉浸式计时器；移动端计时器和开始按钮先于统计摘要 |
| Flashcards | 复习舞台；翻面前隐藏评分，翻面后显示三档评分 |
| Errors | 复习队列 + 筛选工具栏 + 错因展开展示；降低模板统计感 |
| Reports | 阅读型报告：封面摘要、指标带、学习投入/任务回顾/侧栏建议 |
| Settings | 个人资料、偏好、AI 服务、数据管理分区；增大 AI 状态信息字号 |

## 9. 动效

- 页面进入：180ms 淡入 + 5px 位移；不逐个动画卡片。
- 按钮：120ms 色彩/边框反馈，按压缩放 0.985。
- 进度条：360ms 宽度/描边过渡。
- Chart.js：320ms；`prefers-reduced-motion: reduce` 时动画关闭。
- 评分区：160ms 淡入，仅在翻面后出现。
- 所有 CSS 动画受全局 reduced-motion 规则约束；JS 图表动画在创建时再次检查媒体查询。

## 10. 扩展方式

- 新页面使用 `.page-shell`、`.page-header`、`.eyebrow`、`.page-actions`，沿用 `.card`/`.btn`/`.input`。
- 页面专属构图写入对应页面 CSS；跨页面组件样式写入 `components.css`，最终一致性覆盖在 `design-system.css`。
- 不要在前端直接请求 AI，也不要在客户端读取 `.env`。
- 新增颜色、字号、控件尺寸前，优先复用 token。


## 11. Anti-AI-Slop 约束

这一轮精修对模板化视觉做了明确减法：

- 移除了所有页面标题前的英文 Eyebrow；页面由标题、说明和操作直接建立层级。
- 移除卡片标题、统计卡、报告指标前的装饰图标；图标只保留在导航、工具、操作和空状态等真正需要识别的位置。
- 统计数字不再配彩色图标胶囊；数据通过数字、标签、进度和分隔线表达。
- 科目、状态、AI 模式徽标改为「小圆点 + 文本」，不再使用高饱和胶囊。
- Dashboard 的任务、周节奏、最近记录合并为一个连续工作面板；目标、成绩、快捷入口合并为一条安静的辅助轨道。
- Analytics 的图表两两合并为数据面板，而不是四张独立卡片。
- Errors 的错题改为一条复习队列，移除重复的顶部计数卡；计数保留在筛选页签中。
- Notes 改为一个完整的编辑工作区。AI Toolbox 移除顶部状态卡片，工具导航成为轻量列表。
- Settings 主设置区改为分组列表式面板；Reports 主内容合并为阅读纸张。
- 全局移除卡片阴影、装饰性渐变、移动端/弹窗 backdrop-filter 和装饰性 hover 上浮。
- 页面切换仍保留 180ms 的轻微淡入；按钮、评分、进度与图表 feedback 保留；Chart.js 在 reduced-motion 下关闭动画。

### 页面识别度检查

- Dashboard：指标带 + 连续工作面板 + 辅助轨道。
- Planner：任务队列 + 排期工具；平板上排期工具前置。
- Analytics：指标带 + 数据分析面板 + 明细表。
- AI Toolbox：工具列表 + 单工具工作区。
- Notes：文档工作区与笔记索引。
- Focus：计时器为主视觉，统计是背景信息。
- Flashcards：翻卡复习舞台。
- Errors：错题复习队列。
- Reports：长内容阅读纸张。
- Settings：分组设置面板。

即使隐藏 Logo，页面结构、信息语气和交互节奏仍应能识别为 StudyFlow。
